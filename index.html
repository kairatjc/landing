Формат и график

Длительность
Программа рассчитана на ~5 месяцев, но в зависимости от успеваемости можем закончить раньше.
Занятия
2 онлайн созвона в неделю по 1–1,5 часа: одна теория с домашкой и одно практическое занятие, где разбираем домашку.
Контроль
В конце — экзамен в формате интервью на автоматизатора по всем пройденным темам. Кросс-чек каждые 2–3 недели.
Порядок
Порядок изучения смешанный: например, не будем ждать завершения JS, чтобы начать CI/CD.

Программа

Четыре основных блока и опциональные темы.

БЛОК 01

Основы Git + JavaScript/TypeScript

  • Основы Git: clone, add, commit, pull, push, switch, checkout
  • Основы JS I: переменные, типы данных, функции, управляющие конструкции
  • Основы JS II: массивы и методы массивов, объекты, классы
  • Асинхронное программирование: callbacks → promises → async/await, обработка ошибок (try/catch)
  • Основы TypeScript: типизация, интерфейсы, enum
  • GitFlow (ветки main/feature/release), PR/merge, rebase, merge conflicts
БЛОК 02

Automation Frameworks

  • Selenium WebDriver: протокол, локаторы, explicit/implicit waits
  • Архитектура Test Automation Framework, паттерн Page Object
  • Стратегия тестирования: пирамида тестирования, что автоматизировать, а что нет, причины flaky-тестов
  • Архитектура Cypress (в сравнении с Selenium): в чём отличия и почему
  • Playwright: auto-waiting, contexts, работа с несколькими вкладками/браузерами
  • Параллельные тест-раны, headless-режим, кросс-браузерное тестирование
  • API-тестирование (REST), стабы/моки бэкенд-запросов, облачные сервисы (BrowserStack/SauceLabs)
  • Репортинг/логирование/метрики (Allure, Mochawesome, ReportPortal); отладка: Playwright trace viewer, Cypress time-travel debugger
БЛОК 03

CI/CD и инфраструктура

  • Терминал и скрипты: основы Bash и PowerShell
  • Docker: Docker Desktop, CLI, Dockerfile, docker-compose
  • Концепции CI/CD, GitHub Actions (основной инструмент, практика), обзорно — GitLab CI, Azure Pipelines, TeamCity
  • Quality gates (качество кода/сборки/деплоя)
  • Основы SQL для проверки тестовых данных
БЛОК 04

AI-инструменты

  • Тестирование с использованием AI: эффективные промпты, работа с GitHub Copilot
  • Использование AI для диагностики падений тестов — и где результатам AI нельзя доверять вслепую
  • Настройка ИИ агентов, скилов, MCP
ОПЦИОНАЛЬНО

Дополнительные темы

  • Cucumber/BDD
  • Client-side performance testing (Sitespeed.io)
  • Server-side performance testing (JMeter, K6)
  • Браузерный JS: DOM, WebAPI

Кому подойдёт

Мануальным QA

Тем, кто уже тестирует руками и хочет перейти в автоматизацию с реальным кодом и фреймворками, а не с обзорных лекций.

Junior-автоматизаторам

Тем, кто пишет тесты, но хочет разобраться в архитектуре фреймворка, CI/CD и инфраструктуре запусков.

Что нужно заранее

Понимание основ тестирования, готовность делать домашку каждую неделю и сдавать экзамены в формате интервью.
